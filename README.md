# Hotel Reservation System

## Description
A Java console-based Hotel Reservation System developed as part of the CodeAlpha Java Programming Internship.

## Features
- Search available rooms
- Book hotel rooms
- Cancel reservations
- View booking details
- Room categories (Standard, Deluxe, Suite)
- Payment simulation
- File I/O for storing bookings

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- File I/O

## How to Run
1. Compile the project:
   javac *.java

2. Run the project:
   java HotelReservationSystem
